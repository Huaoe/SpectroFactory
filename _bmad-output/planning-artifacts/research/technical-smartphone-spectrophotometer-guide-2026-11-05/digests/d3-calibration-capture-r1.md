# Digest — D3 calibration & capture — round 1 (accessed 2026-11-05)
- CFL Hg calibration lines: 436 nm blue, 546 nm green, 611 nm red (RSC Education worksheet); GoSpectro uses 4 lines 436/488/546/611 (Goyalab getting-started PDF 2018); Spectroscope app (majinsoft) calibrates from CFL starting at 436 nm, disables AWB on iOS, sets ISO 100, recalibrate if lens/spectroscope moves. conf high.
- Image Capture constraints (exposureMode, exposureTime, whiteBalanceMode, colorTemperature, focusMode, iso) implemented in Chrome Android/desktop; "Unsupported platforms: iOS" (w3c/mediacapture-image implementation-status.md, notes Feb 2023). MDN MediaTrackConstraints lists them. webrtcHacks 2022: works Chrome Win/Linux/Android; set exposureMode manual before exposureTime. conf medium (status doc dated 2023 → freshness risk).
- Smartphone JPEG pipeline (demosaic, denoise, sharpen, WB, gamma, compression) breaks linearity; RAW 10–14 bit linear (IntechOpen 2018; MDPI Sensors 2021 used DNG, ISO 100, fixed WB, dark subtraction). conf high.
- Browser tools: spectro-web (gheja, runs fully in-browser, WIP calibration "unstable"); photon-cat/WebSpectrometer (2-point calibration, CSV export, 2024); joshbrew/Digital-Spectroscope LGPL-3.0 web capture + printable 3MF. conf medium.
